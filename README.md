# MT 百家樂系統輔助腳本 (MT Baccarat Auxiliary Script)

本專案為針對目標平台開發之網頁輔助與數據統計工具，旨在提供即時數據紀錄、介面優化及自動化輔助功能，提升使用者操作體驗與數據分析效率。

---

## 📌 功能特點

* **即時數據統計**：自動記錄歷史局數與趨勢，提供精準數據參考。
* **介面輔助優化**：優化網頁版面配置與提示機制，提升操作便利性。
* **高效模組載入**：支援透過 Tampermonkey（竄改猴）進行安全且穩定地遠端腳本載入。

---

## 🚀 安裝與使用說明

### 前置需求
請確保您的瀏覽器已安裝以下擴充功能：
* [Tampermonkey 竄改猴](https://www.tampermonkey.net/)

### 安裝步驟
1. 開啟 Tampermonkey 管理面板並點擊 **新增腳本**。
2. 將本專案提供的用戶腳本程式碼（UserScript）複製並貼入編輯器中。
3. 儲存腳本（`Ctrl + S`）後，前往目標網站即可自動啟動相關輔助功能。
